Cloudflare blocklist

Optional. When set, Block and Unblock also update the Worker's blocklist, so a blocked alias is rejected at the door. Leave all three fields empty to keep using only the Proton filter script.

  1. In the Cloudflare dashboard, open the account home and copy the Account ID. Then go to Storage & databases → KV, open the BLOCKLIST namespace and copy its ID.
  2. Open My Profile → API Tokens → Create Token → Create Custom Token.
  3. Add exactly one permission: Account → Workers KV Storage → Edit. Cloudflare applies it to the whole account, not a single namespace.
  4. Under Account Resources choose Include → your account only.
  5. Optional: set a TTL (expiry date). If the token expires the extension will say "Cloudflare token invalid or expired" and you create a new one. Leave Client IP Address Filtering empty.
  6. Create the token, copy it once, and paste it below. It stays on this device, is never synced and is never included in exports.

Sync between browsers

Keeps the alias registry and Proton label statuses the same in every browser, through the Cloudflare namespace above. Everything is encrypted in the browser before it is sent, with a key made from your passphrase. Cloudflare never sees aliases, tags, sites or notes. If you forget the passphrase the synced data can't be recovered, so keep a JSON export. While sync is locked, aliases, filling and blocking keep working and changes are sent after you unlock.
